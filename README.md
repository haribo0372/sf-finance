# sf-finance

Консольное приложение для учёта личных финансов: пользователи, категории, транзакции (доходы/расходы), бюджеты по
категориям и отчёты. Данные хранятся в JSON-файлах.

## Быстрый старт

```bash
git clone https://github.com/haribo0372/sf-finance.git
cd sf-finance
```

Создайте `.env` в корне проекта (см. [Конфигурация](#конфигурация)):

```properties
FILE_USER=./test-users.json
FILE_TRANSACTIONS=./test-transactions.json
FILE_CATEGORY=./test-category.json
```

Соберите проект:

```bash
mvn -B clean package
```

Артефакт: `target/sf-finance-1.0-SNAPSHOT.jar`.

Запустите с переменными из `.env`.

## Конфигурация

Приложение читает пути к файлам данных из переменных окружения.

| Переменная          | Описание                           | Пример                     |
|---------------------|------------------------------------|----------------------------|
| `FILE_USER`         | Путь к JSON с пользователями       | `./test-users.json`        |
| `FILE_TRANSACTIONS` | Путь к JSON с финансовыми сводками | `./test-transactions.json` |
| `FILE_CATEGORY`     | Путь к JSON с категориями          | `./test-category.json`     |

Пример `.env`:

```properties
FILE_USER=./test-users.json
FILE_TRANSACTIONS=./test-transactions.json
FILE_CATEGORY=./test-category.json
```

Файлы создаются автоматически при первом сохранении. Если файл отсутствует — хранилище при старте пустое.

**Формат файлов** — JSON (сериализация через Jackson)

## Архитектура

```
ru/osipov/sf/finance/
├── SfFinanceApplication.java              # точка входа, консольное меню
├── config/
│   ├── ApplicationConfig.java             # чтение .env
│   └── JsonConfig.java                    # ObjectMapper с JavaTimeModule
├── exception/
│   ├── base/
│   │   └── BaseException.java             # базовое исключение (RuntimeException)
│   └── out/
│       ├── BudgetAlreadyExistsException.java
│       ├── BudgetNotFoundException.java
│       ├── CategoryAlreadyExistsException.java
│       ├── CategoryNotFoundException.java
│       ├── EofException.java 
│       ├── FinancialSummaryNotFoundException.java
│       ├── LoginException.java
│       ├── UserAlreadyExists.java
│       └── ValidateInputException.java
├── models/
│   ├── aggregate/                         # агрегаты (связи)
│   │   ├── FinancialSummary.java          # сводка пользователя: суммы + Map<category, TransactionData>
│   │   └── TransactionData.java           # данные по категории: суммы, бюджет, список транзакций
│   ├── entity/                            # ключевые сущности
│   │   ├── Budget.java
│   │   ├── Category.java
│   │   ├── Transaction.java
│   │   └── User.java
│   ├── enums/
│   │   ├── Labeled.java
│   │   └── TransactionType.java
│   ├── result/
│   │   └── TransactionResult.java         # результат регистрации транзакции: транзакция + уведомления
│   └── warning/
│       └── Warning.java                   # доменное уведомление о превышении
├── modules/
│   ├── printers/
│   │   ├── ReportPrinter.java             # печать отчётов (по категории, краткий, подробный)
│   │   └── WarningPrinter.java            # печать уведомлений (превышение доходов/бюджета)
│   └── readers/
│       └── ConsoleInputReader.java        # обёртка для упрощения валидационного пользовательского ввода
└── services/
    ├── AuthService.java
    ├── CategoryService.java
    ├── TransactionService.java
    ├── base/
    │   └── AbstractEntityService.java     # общая логика load/save JSON (Map<String, T>)
    └── impl/
        ├── AuthServiceImpl.java           # регистрация/логин (SHA-256 + salt)
        ├── CategoryServiceImpl.java       # категории (глобальные, ключ — UPPER_CASE имя)
        └── TransactionServiceImpl.java    # транзакции, бюджеты, отчёты, уведомления
```

**Ключевые решения:**

- **Хранилище** — `Map<String, T>` в `AbstractEntityService`, сериализация через Jackson в JSON. Запись атомарная:
  `.tmp` → `ATOMIC_MOVE`.
- **Пользователи** — `Map<username, User>`, пароль хранится как `SHA-256(salt + password)`, salt = `UUID` пользователя.
- **Категории** — глобальные, ключ — имя в `UPPER_CASE`. Одинаковые имена у разных пользователей запрещены.
- **Агрегаты** — `FinancialSummary` на пользователя: `Map<category, TransactionData>`, где `TransactionData` хранит
  бюджет, суммы и список транзакций.
- **Уведомления** — при `EXPENSE` сервис возвращает `TransactionResult` со списком `Warning` (превышение доходов,
  превышение бюджета, исчерпание бюджета). Печать — в `WarningPrinter`.
- **Ввод** — `ConsoleInputReader` с валидацией и повтором при ошибке. При EOF кидает `EofException`, `main` ловит и
  завершает программу.
- **Слои** — `services` (core: бизнес-логика), `models` (домен), `modules/printers` + `modules/readers` (
  presentation/infra), `config` (infra), `SfFinanceApplication` (CLI).

```bash

```
